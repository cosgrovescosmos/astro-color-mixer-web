Astro Color Mixer Web FAQ & Practical Guide

Selected Band, Hue Radius, Range Mask, refinement passes, and practical browser workflow guidance.

1. What is Astro Color Mixer Web?

Astro Color Mixer Web is a browser-based nonlinear RGB color and luminance refinement tool for astrophotography. It is designed for finishing work after the image has already been stretched and visually prepared, not for raw calibration or linear correction.

It combines practical astro color bands, Selected Band targeting, Range Mask gating, preview diagnostics, and optional multi-pass refinement. Typical uses include emission-nebula shaping, reflection nebulosity lift, galaxy core refinement, magenta-halo cleanup, and neutral background luminance control.

The web app runs entirely client-side in the browser. Your image data stays local to the browser session.

2. Where does it fit in a workflow?

Use Astro Color Mixer Web after calibration, registration/integration, background correction, color calibration, nonlinear stretch, and any early noise reduction or contrast work that should happen before finishing color.

Its normal role is controlled final refinement, not broad upstream correction.

3. What kind of image should I use?

Use a nonlinear RGB image.

  • Good: stretched RGB images with stars present
  • Good: starless RGB images
  • Good: star-reduced RGB images
  • Avoid: raw linear stacks
  • Avoid: data that still needs major global calibration work

Preview is downsampled for speed. Saved output renders from the full-resolution working image.

4. What is Stars Present vs Starless / Star-Reduced?

Stars Present is the safer mode for images that still contain normal stars, bright cores, and halos. It is more conservative around bright stellar structures so aggressive color or luminance moves are less likely to create damaged star cores or harsh highlight artifacts.

Starless / Star-Reduced is intended for images where stars have already been removed or strongly reduced. Since fewer bright stellar features remain, the tool can act more freely on nebulae, galaxies, dust, and faint structures.

This setting does not remove stars and does not create a star mask. It only changes protection behavior.

5. What is the basic workflow?

  1. Load a nonlinear RGB image.
  2. Choose Stars Present or Starless / Star-Reduced.
  3. Start in the Base Pass.
  4. Use H/S/L band sliders for broad adjustments.
  5. Inspect the preview, histogram, polar plot, and probe.
  6. Use Hue Radius and Feather to refine a selected hue family.
  7. Use Range Mask for luminance-targeted work when needed.
  8. Add refinement passes for cleanup or targeted follow-up work.
  9. Save the image or save an Adjustment Set if you want to reuse the setup later.

6. What are the color bands?

  • Red / H-alpha: red emission-dominant structures
  • Orange / Dust & Galaxy Cores: warm dust and galactic core tones
  • Yellow / Warm Stars: warm stellar and transitional yellow hues
  • Green / Cast Control: green cast suppression or selective green shaping
  • Cyan / OIII: cyan-turquoise oxygen-dominant structures
  • Blue / Reflection Nebula: blue reflection nebulosity and cool blue regions
  • Purple / Violet Cleanup: purple-violet cleanup and edge control
  • Magenta / Halo Cleanup: magenta and pink halo cleanup

These are practical editing regions, not claims of strict physical spectral isolation.

7. What do Hue, Saturation, and Luminance do?

  • Hue rotates the selected chroma region around the color wheel.
  • Saturation strengthens or weakens the selected chroma region.
  • Luminance brightens or darkens the selected region without changing the intent of the selected hue family.

These are best used with moderation. Strong moves are usually safer when broken into separate passes.

8. What are Hue Radius and Feather?

Hue Radius sets the outer angular limit on each side of the selected hue center. The current engine treats it as an outer radius, not a total width.

Feather controls how much of that radius is used for falloff instead of full-strength influence.

The Selected Band mask works like this:

  • Strong core: full-strength selection from the hue center out to innerWidth
  • Falloff zone: a smooth decline from innerWidth to outerWidth
  • Off region: no hue-band influence outside outerWidth

For example, if Hue Radius = 45° and Feather = 0.75, then:

  • outerWidth = 45°
  • innerWidth = 45 * (1 - 0.75) = 11.25°
  • strong core = ±11.25°
  • falloff = 11.25° to 45°
  • affected range = center ±45°

This is why a radius value such as 45° affects more than 45° total width. It affects 45° on each side of the selected hue center.

9. What is Range Mask?

Range Mask limits adjustments by luminance rather than hue. You define a low/high interval and feather the edges so the selected adjustment acts mainly inside the chosen brightness band.

This is useful when you want a hue-band move to act mainly in shadows, midtones, background, or highlights instead of everywhere that hue appears.

10. What is Neutral / Low-Saturation?

Neutral / Low-Saturation is not selected by hue angle. It is selected by low chroma / low saturation, where hue becomes unreliable.

That makes it useful for:

  • neutral background luminance shaping
  • gray dust regions
  • weak-color structures
  • subtle sky/background cleanup

When this mode is active, Hue Radius does not apply. Feather still matters because it softens the transition into more saturated pixels.

11. What are Refinement Passes?

Refinement Passes let you process the image in stages. They are not Photoshop layers. They are sequential adjustments that operate on the working result from the previous enabled pass.

A typical pattern is:

  • Base Pass for broad global color setup
  • a second pass for localized cleanup
  • a third pass for luminance-specific or halo-specific work

12. What do the probe, histogram, and polar plot do?

  • Probe samples the local preview pixel and reports luminance, hue, and saturation.
  • Histogram shows luminance distribution and is especially useful with Range Mask.
  • Polar plot shows hue angle and saturation distribution in a compact visual form.

These tools help you understand what the image is doing before you commit to stronger edits.

13. What are mask views?

Mask views show how the current targeting logic is behaving. In general:

  • white or bright regions are more included
  • black or dark regions are less included
  • different mask views let you inspect selected hue, luminance gating, or combined influence

If a strong adjustment is surprising, inspect the mask view first.

14. Why can preview differ from saved output?

Preview uses downsampled data so the tool stays responsive. Saved output renders from the full-resolution working image.

This means tiny local detail differences can exist, but the overall adjustment direction should match as long as preview is current.

15. What file formats are supported?

  • PNG export is supported
  • TIFF import/export is supported when the included browser-side TIFF I/O code and available browser memory allow it

Large TIFF files can be memory-intensive in a browser session.

16. What are Adjustment Sets?

Adjustment Sets are JSON files that store the working state of the app. They can preserve pass order, H/S/L values, selected-band settings, Hue Radius and Feather, Range Mask settings, Neutral / Low-Saturation settings, and related workflow state.

Starter Presets are canned starting points. Adjustment Sets are your saved session state.

17. Common mistakes

  • using the tool on linear data
  • making excessive hue shifts where smaller targeted passes would be safer
  • changing Range Mask inside an existing global pass unintentionally
  • ignoring the mask preview before strong edits
  • expecting hue to be meaningful in neutral background
  • forgetting that preview may be stale after changes
  • pushing browser memory too hard with very large TIFFs

18. Example workflows

A. Faint blue reflection nebulosity lift

  1. Start in Base Pass or create a dedicated reflection pass.
  2. Increase Blue / Reflection Nebula saturation modestly.
  3. Inspect the band mask.
  4. Reduce Hue Radius if blue stars are moving more than the nebulosity.
  5. Use Range Mask if the goal is faint blue structure rather than highlights.

B. Magenta halo cleanup

  1. Create a new refinement pass.
  2. Work mainly in Magenta / Halo Cleanup, with Purple / Violet Cleanup if needed.
  3. Use a narrower Hue Radius and enough Feather to keep the transition smooth.
  4. Use Range Mask if the artifact is concentrated in brighter star-adjacent regions.

C. Neutral background luminance control with Range Mask

  1. Use the Luminance tab.
  2. Work through Neutral / Low-Saturation rather than a hue band.
  3. Enable Range Mask and target the dim background interval.
  4. Use Feather to keep the transition soft into more saturated structures.
