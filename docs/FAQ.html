Astro Color Mixer FAQ & Practical Guide

Browser-based nonlinear RGB color and luminance refinement for astrophotography.

What is Astro Color Mixer?

Astro Color Mixer is a nonlinear RGB finishing tool built around practical astro color bands, luminance targeting, preview diagnostics, and optional multi-pass refinement.

What kind of image should I use?

Use nonlinear RGB images. The tool supports stars-present and starless/star-reduced workflows, but is not intended for raw linear calibration data.

Stars Present vs Starless / Star-Reduced

Stars Present is safer for bright star cores and halos. Starless / Star-Reduced allows more freedom for nebulae, dust, and faint structures after stars have been reduced or removed.

Standard vs Advanced workflow

Standard mode stays compact for broad color work. Advanced mode exposes Refinement Passes, Range Mask controls, and more targeted pass-aware editing.

Color Mixer sliders

Hue rotates color direction, Saturation changes color strength, and Luminance brightens or darkens the active color family.

Selected Band width and feather

Width controls how broad the selected hue family is. Feather controls how softly the selection falls off into neighboring colors.

Range Mask

Range Mask constrains an edit by luminance using Low, High, and Feather. Presets provide starting points for shadows, midtones, highlights, faint signal, and bright cores.

Neutral / Low-Saturation

When saturation is very low, hue becomes unreliable. Neutral / Low-Saturation provides a luminance-focused path for gray background, dust, and weak-color structures.

Refinement Passes

Refinement Passes are sequential adjustment passes. Base Pass is for broad work; later passes are for targeted cleanup. They are not Photoshop layers.

Probe, histogram, and polar plot

The probe samples the preview, the histogram shows preview luminance distribution, and the polar plot shows hue/saturation distribution. Together they help guide Range Mask and color-band choices.

Preview vs saved output

Preview is downsampled for responsiveness. Saved output renders from full-resolution data, so fine details can differ slightly.

TIFF import/export

The web app supports browser-side TIFF import and export when the included TIFF I/O code and available browser memory allow it. Large files can be memory-intensive.

Adjustment Sets

Adjustment Sets are JSON files that store the working state of the app. Starter Presets are canned starting points; Adjustment Sets are your saved session state.

Common mistakes

Common mistakes include using linear data, making extreme hue shifts, ignoring mask views, assuming hue is meaningful in neutral background, and pushing image sizes beyond available browser memory.
